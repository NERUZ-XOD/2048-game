# Changelog

All notable changes to the Retro 2048 project will be documented in this file.

## [1.0.0] - 2025-03-28

### Added
- Initial release of the game with retro pixel art style
- Custom animations for tile movements, merges, and spawns
- Sound effects for game actions
- Game state saving and loading functionality
- High score tracking
- Retro-styled UI elements including:
  - Main menu
  - Game over screen
  - Help menu
  - Sound toggle notification
  - Save game confirmation
- Executable file for Windows included in the repository

### Technical Details
- Implemented using Python with Tkinter
- Fixed tile positioning system (72x72 pixel tiles with precise grid coordinates)
- Optimized animations for smooth gameplay
- Robust file handling for game saves and high scores
